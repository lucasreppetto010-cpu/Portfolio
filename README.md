## 📖 Sobre

Este é meu portfólio pessoal, criado para:

- ✅ Apresentar minhas **habilidades técnicas** (HTML, CSS, JavaScript)
- ✅ Exibir meus **projetos desenvolvidos** com links para demonstração
- ✅ Fornecer **informações de contato** e redes sociais
- ✅ Demonstrar meu **crescimento profissional** como desenvolvedor

O design foi pensado para ser **moderno, responsivo e intuitivo**, com uma paleta de cores preta e verde que remete à tecnologia e inovação.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🌐 **Site Responsivo** | Adapta-se perfeitamente a dispositivos móveis, tablets e desktops |
| 🎨 **Design Moderno** | Interface clean com animações suaves e interatividade |
| 📱 **Menu Mobile** | Navegação simplificada para smartphones com animação lateral |
| 🖼️ **Galeria de Projetos** | Cards interativos com hover e link para demonstração |
| 📬 **Formulário de Contato** | Campos para nome, email, celular e mensagem |
| 📍 **Informações de Localização** | Card com endereço, WhatsApp e email |
| 🔗 **Redes Sociais** | LinkedIn, GitHub, Instagram e WhatsApp integrados |
| 🎯 **Scroll Suave** | Navegação fluida entre as seções |
| 🖱️ **Animações** | Efeitos de hover, escala e flutuação em elementos |
